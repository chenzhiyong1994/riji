# 连续蒙皮人体参考场景

本目录保存 80 个动作库使用的人体基础：CC0 来源资产、原始 Blender 场景、弯举参考动画和四个参考帧。`source/manifest.json` 记录固定上游版本与逐文件哈希。

`build_refined.py` 是 Blender 制作入口，包含项目编排的动作、器械、肌群分区和材质。`refined-curl.blend` 可在 Blender 5.2 打开；`reference-frames/` 供动画导入和关键帧检查复用。

这些材料保留制作过程的技术记录。姿势复核状态以 [80 个动作库说明](../../exercise-library/README.md) 为准，历史记录中的画面通过不代表动作姿势规范。
