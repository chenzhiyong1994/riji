# 日跻隐私说明

适用版本：Android / iOS 1.1.3。更新日期：2026-09-20。

日跻无需账号，不收集或上传训练记录、身体数据和设备标识。App 不包含广告、分析统计或登录 SDK。Android 不声明网络权限；iOS 通过本地资源加载、CSP、原生导航白名单与内容规则阻断外部请求。

训练记录、个人模版、收藏、身体数据和设置仅保存在应用的私有存储中。Android 使用 SharedPreferences，关闭系统云备份及设备迁移备份；iOS 使用原子写入的 Application Support 文件，将训练数据目录排除系统备份，WKWebView 使用非持久化网站数据存储。设备丢失、应用卸载或本地存储损坏可能导致记录丢失，因此建议定期自行导出备份。

导出或导入备份由用户主动操作，通过 Android / iOS 系统文件选择器选择位置。若选择 iCloud Drive 或第三方网盘提供的位置，相应文件会按该服务的规则处理；日跻本身不向该服务联网。JSON 备份没有应用层加密，请放在自己信任的位置。两端格式兼容，导入需在 App 内确认后才替换本机记录。

iOS IPA 的个人签名发生在所用安装工具中；工具的账号处理和隐私规则由其提供方决定，日跻 App 不读取签名工具中的账号或密码。

项目介绍网站托管于 GitHub Pages，访问网站及下载安装包会向 GitHub 发起网络请求，适用 GitHub 的隐私政策。网站不添加分析统计、广告或第三方追踪脚本；App 的离线使用不依赖访问网站。
