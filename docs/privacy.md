# 日跻隐私说明

适用版本：1.0.6。更新日期：2026-09-08。

日跻无需账号，不收集或上传训练记录、身体数据和设备标识。App 不包含广告、分析统计、登录 SDK，也不声明网络权限。

训练记录、个人模版、收藏、身体数据和设置仅保存在 Android 应用的私有存储中。系统云备份及设备迁移备份关闭。设备丢失、应用卸载或本地存储损坏可能导致记录丢失，因此建议定期自行导出备份。

导出或导入备份由用户主动操作，通过 Android 系统文件选择器选择位置。若选择第三方网盘提供的位置，相应文件会按该服务的规则处理；日跻本身不向该服务联网。JSON 备份没有应用层加密，请放在自己信任的位置。

项目介绍网站托管于 GitHub Pages，访问网站及下载安装包会向 GitHub 发起网络请求，适用 GitHub 的隐私政策。网站不添加分析统计、广告或第三方追踪脚本；App 的离线使用不依赖访问网站。
