# 训练模板与个人计划

1.1.0 起，在「训练 → 训练模板」按训练经验、目标和器械筛选，查看一周安排、动作顺序及组数、次数或秒数、休息时间，点击「添加到我的计划」。

一个模板可包含多份计划，每份对应一次训练。一次添加整个模板后，可直接选择其中一份编辑，也可从「我的计划」打开。添加不会开始训练，不会改动进行中的训练、历史或每周目标；重复添加生成新副本，并为重名计划加编号。

共 8 个模板、16 份计划，全部使用现役 80 项动作库的固定 ID。时间为估计值，可按热身和恢复需要延长；安排文字不会自动生成日历或提醒。内容为一般训练起点，不是按个人状况生成的处方。居家徒手模板明确注明拉类训练不足；减脂场景不承诺体重变化。

## 编辑与开始训练

- 可修改名称、说明、动作顺序、动作数量，以及每个动作的目标组数（1–20）、次数（1–1000）或秒数（1–86400）、休息秒数（0–3600）。休息为 0 时不启动自动计时。
- 新建计划的动作默认「沿用上次记录」。点击「设置组数与次数」可固定目标；也可将已固定的动作恢复为沿用上次记录。取消编辑不会保存草稿。
- 有目标时，开始训练使用计划的组数、次数或秒数，所有组重置为未完成普通组。重量复用上次同记录方式的动作数据，新增组沿用上一组重量；无记录时为 0，训练时可修改。
- 没有目标的旧计划仍复用最近一次该动作的组数据；没有历史时默认三组。既有动作 ID、历史引用、收藏及自定义动作不变。
- 计划说明会带入本次训练备注；修改个人计划不会反向修改内置模板，也不会改动已开始的训练。自定义动作改了记录方式后，如目标不匹配，开始时提示先编辑目标。

## 本地数据契约

来源：`app/src/main/assets/training-templates.js`；交互：`app.js`；存储与启动：`core.js`。

个人计划保留 `id / name / exerciseIds`，增加可选字段 `notes` 和 `targets`。`targets` 按动作 ID 映射到 `{ sets, reps, seconds, restSeconds }`；只允许引用本计划中的动作。计时动作的 `reps` 通常为 0，计次动作的 `seconds` 通常为 0。开始时验证目标与动作当前记录方式匹配。

启动后对应训练动作携带可选 `restSeconds`，覆盖全局默认休息时间。自由添加的动作仍用全局休息设置。计划与进行中训练的新字段在重启、JSON 导出及导入时保留，错误目标和超过 500 份计划的添加会整体拒绝。

`schemaVersion: 1`、`jilian-backup` 格式版本 1 保持不变，新版读取旧版数据时不补写目标。旧版应用不识别新可选字段，降级后可能丢失计划目标与说明；应使用新版恢复含新目标的备份。

## 内容依据与维护

具体动作组合、分日方式、起始组数及时间由本项目编排，未声称为下列机构发布的原版模板：

- [ACSM 2026 抗阻训练指南说明](https://acsm.org/resistance-training-guidelines-update-2026/)：规律参与、按个人目标调整负荷和训练量，徒手与居家训练也可有效。
- [CDC 成年人活动指南](https://www.cdc.gov/physical-activity-basics/guidelines/adults.html)：每周肌力活动与有氧活动的总体建议。单个模板不代表已覆盖全部建议活动量。

新增模板时保持稳定模板 ID 和动作 ID，并运行 `node --test tests/plans.test.cjs` 与 `npx playwright test tests/browser/plans.spec.cjs`；前者遍历所有模板，验证添加、启动、记录方式及备份往返，后者验证用户流程和窄屏。
