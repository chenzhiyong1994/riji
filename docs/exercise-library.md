## 自定义动作

- 入口：“动作”右上角“自定义动作”，或训练/模版的动作选择器底部“新建自定义动作”。搜索不到时也会显示新建按钮。
- 填写名称、训练部位、器械、记录方式，可补充最多 2,000 字符的动作说明。新动作使用统一缺省图，加入训练、模版和收藏的流程与内置动作一致。
- 支持重量＋次数、仅次数、时间（秒）。仅次数不显示重量输入，计时使用秒数；这两种方式不产生重量容量。说明、记录方式及删除状态随本地 JSON 备份保留。
- 在自定义动作详情中“编辑动作”或“删除动作”。删除从动作库及收藏移出；进行中训练、已完成历史和模版保留，可从“已删除”分类恢复。
- 改名和说明不改写已有训练快照。已经进入进行中训练或历史的动作不可改记录方式；需要另一种方式时新建动作，以免混淆统计。恢复遇到同名动作时，先编辑名称再恢复。

## 旧数据兼容

精选项在 `app/src/main/assets/catalog.js`，被移出项的兼容元数据在 `legacy-catalog.js`。原来的 1,191 个 ID 全部仍可解析；不批量重写或删除用户存储。

“已用旧动作”只出现于已有训练、历史、模版或收藏引用了移出项时，里面只展示个人用过的旧动作。旧模版可以继续启动；已删除的自定义动作仍能供旧模版使用。

包名、签名、原生存储键、浏览器存储键和备份格式标识继续沿用。`customExercises` 新增可选字段 `notes`、`archived`，导入旧备份时分别默认空字符串、false。
